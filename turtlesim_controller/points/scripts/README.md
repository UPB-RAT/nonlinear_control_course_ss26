# Points Generating Scripts

## About:
- The scripts in this directory that were used to generate points in this project were predominantly crafted by ChatGPT, though the GPT-4.0 model. 
- I did modify the scripts a bit to generate points better optimized for turtlesim but they were still predominantly written by ChatGPT.
- The "m.json" points were the original example points for this project. But years later, these other points were generated to better demonstrate the capabilities of this repo.
